# Лабораторна робота № 2

**Тема:** Проектування алгоритмів синтезу моделей.

**Мета:** Закріпити навички проектування алгоритмів синтезу моделей.

Алгоритм синтезу прогнозних моделей (АСМ) на основі полінома Колмогорова-Габора спроектовано в UML
(PlantUML замість Rational Rose) і реалізовано мовою Python.

## Файли

| Файл | Що робить |
|---|---|
| `kg_asm.py` | АСМ: опорна модель, умовні й нормальні рівняння Гауса, метод Гауса, СКВ, горизонт прогнозування, переваги ОПР (метод аналізу ієрархій) і вибір моделі |
| `cli.py` | Граничний клас `SynthesisCLI`: синтез заданої моделі або вибір моделі за перевагами ОПР з командного рядка |
| `example.py` | Перевірка АСМ на розв'язаному прикладі методички (сторінки 46–51) і порівняння з надрукованими числами |
| `individual.py` | Тестування АСМ у процесі формування переваг ОПР за індивідуальним рядом (seed = 7) |
| `diagrams/` | Діаграми PlantUML: прецедентів, діяльності, класів, послідовностей, станів; `build.sh` рендерить їх і діаграму класів, отриману зворотним проектуванням (pyreverse) |
| `data/` | Первинний опис з методички та індивідуальний ряд |
| `outputs/` | Таблиці результатів і рисунки |

## Запуск

```bash
uv run python lab-02/example.py
uv run python lab-02/individual.py
uv run python lab-02/cli.py lab-02/data/individual_series.csv --model "1; F1; F1^2"
uv run python lab-02/cli.py lab-02/data/individual_series.csv --select --pairwise "1,1/3,3; 3,1,5; 1/3,1/5,1"
sh lab-02/diagrams/build.sh   # потрібні PlantUML і Graphviz
```
