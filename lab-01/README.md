# Лабораторна робота № 1

**Тема:** Формування масиву вхідних даних на основі первинного опису об’єкта дослідження.

**Мета:** Закріпити навички формування масиву вхідних даних на основі первинного опису об’єкта дослідження.

Надбудову «Аналіз даних» Microsoft Excel, на яку спирається методичка, замінено на Python.

## Файли

| Файл | Що робить |
|---|---|
| `asm.py` | Алгоритми синтезу моделей: лінійна опорна модель за МНК (нормальні рівняння Гауса) і багаторядний МГУА з критерієм регулярності |
| `mvd.py` | Модуль первинної обробки МВД (завдання до самостійного виконання): закон розподілу, видалення неінформативних показників, сортування, кластеризація спостережень і показників; працює і з командного рядка |
| `experiments.py` | Дослід 1 (масиви X1–X5 із 2, 3, 6, 9, 18 показниками) і дослід 2 (сортування за \|Δy\|) |
| `individual.py` | Тестування модуля за індивідуальним МВД і порівняння шести способів формування МВД |
| `plotting.py` | Спільне оформлення рисунків |
| `data/` | Згенеровані масиви: `exp1_X*.csv`, відсортовані `exp2_X*.csv`, індивідуальний МВД |
| `outputs/` | Таблиці результатів (CSV, JSON) і рисунки для звіту |

## Запуск модуля первинної обробки

```bash
uv run python lab-01/mvd.py lab-01/data/individual_mvd.csv --target y --cv-min 0.01 --r-min 0.9 --sort abs_dev --out processed.csv
```

Модуль друкує звіт у форматі JSON: закони розподілу, видалені показники, кластери показників і спостережень.
