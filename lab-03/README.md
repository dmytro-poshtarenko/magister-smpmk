# Лабораторна робота № 3

**Тема:** Проектування синтезатора моделей.

**Мета:** Закріпити навички проектування синтезатора багатошарових моделей на основі нейромереж.

Синтезатор моделей (агрегати A1–A6 з рисунка 3.1 методички) спроектовано в UML (PlantUML замість Rational Rose)
і реалізовано мовою Python. Багатошаровий алгоритм синтезу виконує етапи 1–4 структурування МВД із завдання
роботи. Синтезатор застосовано до індивідуального об’єкта моніторингу: модель стану об’єкта (завдання 1) і
ієрархія моделей для дворівневого довготривалого прогнозування (завдання 2).

## Файли

| Файл | Що робить |
|---|---|
| `synthesizer.py` | Синтезатор: A1 `MVDFormer` (первинна обробка з роботи № 1), A2 `TestScenario`, АСМ `LinearASM`, `PerceptronASM`, `PolynomialASM`, `MultilayerASM` (етапи 1–4), A4 `ModelTester`, A5 `Controller`, A6 `AlgorithmConstructor`, `ModelSynthesizer` |
| `hierarchy.py` | Ієрархія моделей: річний МВД і модель верхнього рівня, моделі кварталів, критерій балансу, каскадно-регресійна модель, рекурентний довготривалий прогноз |
| `monitoring.py` | Індивідуальні дані: умовний гідрохімічний пост на річці, 32 роки × 4 квартали (seed = 3) |
| `experiments.py` | Досліди обох завдань, перевірка стійкості висновків на 20 реалізаціях даних, рисунки |
| `diagrams/` | Діаграми PlantUML (класів, послідовності, діяльності) і схема ієрархії моделей (Graphviz); `build.sh` рендерить їх |
| `data/` | Квартальний МВД і річні планові показники |
| `outputs/` | Підсумок `summary.json`, результати за реалізаціями `seeds.csv`, рисунки |

## Запуск

```bash
uv run python lab-03/experiments.py              # приблизно 3 хвилини разом із 20 реалізаціями
uv run python lab-03/experiments.py --seeds 0    # лише індивідуальні дані
sh lab-03/diagrams/build.sh                       # потрібні PlantUML і Graphviz
```
