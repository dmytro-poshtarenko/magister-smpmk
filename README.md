# magister-smpmk

Лабораторні роботи з курсу «Синтез моделей та проектування моделюючих програмних комплексів»
(Черкаський державний технологічний університет, магістратура, 2026).

| Робота | Тема | Папка |
|---|---|---|
| № 1 | Формування масиву вхідних даних на основі первинного опису об’єкта дослідження | [lab-01](lab-01) |
| № 2 | Проектування алгоритмів синтезу моделей | [lab-02](lab-02) |

## Запуск

Потрібні Python 3.14 і [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run python lab-01/experiments.py   # досліди 1 і 2
uv run python lab-01/individual.py    # модуль первинної обробки МВД на індивідуальних даних
uv run python lab-02/example.py       # АСМ на прикладі методички
uv run python lab-02/individual.py    # вибір прогнозної моделі за перевагами ОПР
uv run pytest                         # тести
```
